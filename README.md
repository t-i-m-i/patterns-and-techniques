# Patterns and Techniques

A collection of patterns and techniques I've used in commercial projects,
detached from their original codebase and simplified down to the pattern
itself.

- `backend/` - server-side patterns (caching, pagination, job recovery, etc.)
- `frontend/` - client-side patterns (React/UI)

Each file is self-contained and anonymized - no real domain names, business
logic, or proprietary code, just the shape of the solution.
